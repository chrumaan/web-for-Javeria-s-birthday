JAVERIA BIRTHDAY EXPERIENCE — READ ME

This folder contains a complete mobile-friendly birthday website.
- index.html — the full website
- assets/ — the five photos you supplied, copied into the site

PREVIEW:
Keep the assets folder next to index.html, then open index.html in a modern browser.
The photos are already included and the cake, quiz, animations and original synthesized music button work locally.

EMAIL QUIZ:
When Javeria submits her quiz, the website opens her device's email app with the answers addressed to m.rumaan7860@gmail.com. She must press Send. This is intentionally not a silent email sender. If she has no email app configured, she can save the answers as a text file and send them another way.
For guaranteed automatic collection, you would need a form service or backend configured by you; this static website does not secretly transmit anyone's answers.

MUSIC:
The top button plays a small original synthesized melody. A YouTube link opens Hassan Raheem's music search. The site does not bundle copyrighted songs.

PUBLISH FREE WITH GITHUB PAGES:
1. Create a GitHub repository, e.g. javeria-birthday.
2. Upload index.html and the entire assets folder, preserving the folder structure.
3. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for the public URL to appear in Settings > Pages.
5. Test the link on your phone before sharing it.
6. Anyone who has the public URL may view the page and its included photos. Only publish/share photos you are comfortable sharing.

IMPORTANT:
The quiz includes personal questions and emotional hints. It is designed to be affectionate without requiring her to respond romantically. Respect her comfort and privacy.
